A common language for exercises.

The Open Exercise Schema describes an exercise so any tool can identify it, explain it, and record it the same way. The catalogue is {{.Count}} exercises in that format, free to use.

Read the specBrowse the catalogue

Identity that lasts

Stable IDs such as oec:barbell-back-squat, with old IDs, aliases and retired records that keep resolving.

Numbers that mean one thing

Each exercise says what a logged load is: the whole bar, one dumbbell, weight added to the body, or assistance taken off.

Origin on every value

Licences, sources, a review status, and pointers to each value a machine produced and no person has checked.

What a record covers

Identity
ID, name, aliases by kind, previous IDs, status, translations
Classification
Modalities, movement patterns, mechanics, force, kinetic chain, laterality, planes, contraction, level
Setup
Position, incline, grip, stance, where the load sits, range
Anatomy
A four-level muscle tree with roles, plus joints and their actions
Equipment
Required groups with alternatives, and optional items
Measurement
Recording profiles, load kind and convention, per-side counting, where e1RM and volume make sense
Instructions
Setup, steps, breathing, cues, common faults and corrections, safety
Relations
Variations, regressions, progressions, substitutes, antagonists
Provenance
Licence, sources, review status, generated-value pointers
